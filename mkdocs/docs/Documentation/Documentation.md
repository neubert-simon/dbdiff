# Documentation

## Technical Documentation
High level documentation like architectural decisions and project layout are described here.

Implementation details are documented via `Javadoc`, which can be viewed when view at:<br>
[DBDiff - Javadoc Documentation](https://neubert-simon.github.io/dbdiff/javadoc/)

Only methods with a visibility higher than `private` are documented. Since private methods aren't exposed as part of a class interface, they are treated as the implementation detail of the class itself.
If there is a need for explanation, comments will be addded to enable maintainability.
